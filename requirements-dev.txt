# Development / test dependencies.
#
# Kept separate from requirements.txt so that installing the app does not drag in
# a test runner. That split matters in a container image — test tooling is dead
# weight in production and widens the dependency surface a scanner has to care
# about — and it documents which packages are needed merely to *check* the code
# versus to *run* it.
#
#   pip install -r requirements-dev.txt      # includes the runtime set below
#
# Most of the suite needs nothing but pytest and the standard library: the
# parsers are imported lazily inside fs_tools.read_file, and the agent-loop
# tests use a fake LLM client. `pip install pytest && pytest` still works on a
# bare interpreter. tests/test_pg_store.py is the exception: it needs psycopg,
# pgvector and numpy plus a running Postgres, and skips itself (with the reason
# printed) when any of them is missing.

-r requirements.txt

pytest==9.2.0
