# Runtime dependencies.

# `openai==0.28.1` used to head this list and has been removed: nothing in the
# project imports it. The LLM client here is Groq (`llm_file_assistant.py:4`).
# A dependency nobody imports is not free — it gets installed, it gets scanned by
# every vulnerability tool, and it misleads the next reader about which provider
# this project actually talks to. That particular pin was also pre-1.0 `openai`,
# whose API was reshaped entirely in 1.0, so anyone taking the hint would have
# written code against an interface this project never used.
